# Fonts

Self-hosted latin subsets, served from `/fonts/` and declared in `src/app/globals.css`.

| File | Family | Weights | Source |
| --- | --- | --- | --- |
| `syne-latin.woff2` | Syne (variable) | 400 to 800 | https://fonts.google.com/specimen/Syne |
| `instrument-sans-latin.woff2` | Instrument Sans (variable) | 400 to 700 | https://fonts.google.com/specimen/Instrument+Sans |

Both families are licensed under the SIL Open Font License 1.1. Downloaded on 2026-11-05 from the Google Fonts CSS API (`css2?family=Syne:wght@400..800&family=Instrument+Sans:wght@400..700`).
